# NEET WALA BOT - Single File Railway Version

No `bot/` package is required. Upload these files directly to the GitHub repository root.

Railway Variables:
- TELEGRAM_BOT_TOKEN
- GEMINI_API_KEY
- GEMINI_MODEL=gemini-3.6-flash

Commands:
/start
/help
/quiz कोशिका 20
/chapter मानव प्रजनन 20
/leaderboard
/profile

PDF भेजने पर bot PDF text से MCQ बनाने की कोशिश करता है.
